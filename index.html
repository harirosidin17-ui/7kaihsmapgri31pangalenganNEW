Bantuan & Panduan

Cara memakai Dashboard 7 KAIH SMA PGRI 31 Pangalengan

Untuk Siswa

  1. Login dengan NIS dan password SMAPGRI31 (atau password yang diubah).
  2. Buka menu Isi Form → jawab 7 kebiasaan → Kirim Data.
  3. Satu hari = satu isian (kirim ulang = memperbarui isian hari itu).
  4. Lihat progres di Beranda dan Rapor 7 KAIH.

Untuk Guru

  1. Login dengan NUPTK (atau nama depan jika NUPTK “-”).
  2. Pantau Beranda (pengingat belum isi / pasif).
  3. Rekapitulasi → filter kelas → unduh PDF/Excel/Word.
  4. Rapor → pilih siswa atau Cetak Rapor Kelas.

Untuk Admin

  1. Kelola siswa/guru di Setting.
  2. Upload logo, KOP, tema, wallpaper.
  3. Data online memakai Firebase (config ditanam di file index.html sebelum deploy).
  4. Backup data berkala (tombol Backup di Setting).

Data Online

Netlify = hosting website. Firebase = penyimpanan data bersama. Perubahan Admin (tema, logo, KOP, daftar siswa, akses rapor) otomatis tampil sama di semua perangkat.

Lihat status di Setting → Data Online. Tombol “Unggah Semua Data Lokal” dipakai sekali bila Anda punya data lama di browser ini.

Lokal

Agar siswa & guru melihat data yang sama di perangkat berbeda. Buat project di Firebase Console → aktifkan Firestore → tanam config di bagian atas file index.html lalu deploy ulang. Pada perangkat Admin, status di bawah harus “Online”.

Salin dari Firebase Console → Project settings → Your apps → Config. Bukan link Netlify/website. Contoh berisi apiKey dan projectId.
